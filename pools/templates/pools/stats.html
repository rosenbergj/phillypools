How this is measured. No cookies are set for this and no third-party analytics are used. Visitors are counted with a hash of IP address and browser that is re-salted every night, so the same person is countable within a day and unlinkable across days; IP addresses and browser strings are never stored.

“Confirmed browsers” are visitors seen requesting an endpoint only the page's own JavaScript calls — proof a real browser ran the page. Visitors who load a page and never filter or click a pin can't be confirmed either way, so the true human number sits between the two figures.
