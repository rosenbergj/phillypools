How this is measured. No cookies, no third-party analytics. Visitors are counted with a hash of IP address and browser that is re-salted nightly, so the same person is countable within a day and unlinkable across days; the addresses and browser strings themselves are never stored.

“Confirmed browsers” are visitors whose browser ran the page's own JavaScript — proof a real browser rendered the page rather than a bot fetching the HTML. The true human number sits between the two figures, nearer the confirmed one. Robots are left out when they name themselves, send a browser string no real browser would, probe for paths only a scanner wants, or arrive from a hosting provider and never run any JavaScript; anyone caught is discounted for that whole day.
