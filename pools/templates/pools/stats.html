How this is measured. No cookies are set for this and no third-party analytics are used. Visitors are counted with a hash of IP address and browser that is re-salted every night, so the same person is countable within a day and unlinkable across days; IP addresses and browser strings are never stored.

“Confirmed browsers” are visitors whose browser ran the page's own JavaScript — proof a real browser rendered the page, not just a bot that fetched the HTML. Every page load now reports this, so the gap to the visitor count is mostly people with JavaScript disabled or blocked, plus any bot that slipped past the crawler check without running scripts. The true human number sits between the two figures, nearer the confirmed one.

The three-way split counts a page as a distinct URL, so reloading the map is still one page while the map plus a pool's detail page is two, and it counts as “used it” a pin click, a neighborhood picked off the map, or any filter. Only confirmed browsers are split: for anyone else, doing nothing is indistinguishable from running no JavaScript, which would file every crawler as a reader who lost interest.

Individual rows are kept {{ raw_retention_days }} days ({{ raw_rows }} on hand now) and then deleted; the daily totals above are permanent.
